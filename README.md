# Placealgo

Static version of [www.placealgo.com](https://www.placealgo.com), hosted on GitHub Pages.
The compatibility algorithm runs in the visitor's browser (`assets/placealgo.js`); there is no server.

- `index.html` – welcome page
- `about/`, `science/`, `contact/`, `disclaimer/` – info pages
- `place_manualgo/` – Basic Compatibility
- `place_manualgo3/` – Name-Only Compatibility
- `place_manualgo4/` – Complete Compatibility Test
