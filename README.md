# Placealgo

Website for [www.placealgo.com](https://www.placealgo.com), hosted on GitHub Pages (built with Jekyll).
The compatibility algorithm runs in the visitor's browser (`assets/placealgo.js`); there is no server.

## Editing texts
Use the browser editor at https://app.pagescms.org (settings in `.pages.yml`).
Editable: Home page, About, Science, Contact, Disclaimer.

## Files
- `_layouts/` – shared header, footer and page templates
- `index.html`, `about/`, `science/`, `contact/`, `disclaimer/` – text pages
- `place_manualgo/` – Basic Compatibility
- `place_manualgo3/` – Name-Only Compatibility
- `place_manualgo4/` – Complete Compatibility Test
- `assets/` – stylesheet, JavaScript and images (`assets/images/`)
